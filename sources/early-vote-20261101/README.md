# early-vote-20261101

Read 2026-11-01 ~12:45 PST in Max's Chrome (one tab) from https://onpointpolitics.us/maps/early-vote/<state>, the
"THEN AND NOW · SAME DAY · MODELED" block (party lead of ballots cast by the same day before Election Day in 2022, 2024, 2026;
D positive) and the party-basis line ("Party registration as the state reports it." -> registration; "Party modeled by
On Point Polling..." -> modeled). shift_vs_2022 = 2026 minus 2022.

Changes vs the Oct 26-27 read: KS, NE and FL now publish a 2022 same-day baseline (were NA), so under method 2.1 they are
counted; AK's page now says party is modeled (Oct 26 file said registration), so AK is no longer counted. NC's 2024 same-day
lead reads R +0.6 (Oct 26 file had +0.6, sign likely misread; 2024 is not used by the model). NH has a page but was never in
the file (no tracked early-vote race basis), left out.
